# Практическая работа №1 — эмулятор оболочки

Дисциплина: «Конфигурационное управление». Группа: ИКБО-60-25.
Вариант: 9. Текущее состояние: этап 1 — консольный REPL.

## Описание

Программа имитирует минимальную командную строку UNIX-подобной ОС.
Она показывает приглашение `vfs9$ `, принимает ввод, выделяет команду
и аргументы, обрабатывает ошибки и повторяет ввод до команды `exit`.

`vfs9` — условное имя виртуальной файловой системы (VFS).
На этапе 1 VFS ещё не загружается. Команды `ls` и `cd` являются заглушками:
выводят своё имя и аргументы без обращения к файловой системе.

## Требования к среде

- Python 3.13; работа проверена с Python 3.13.12 на Windows.
- Для `run.bat` команда `python` должна быть доступна в терминале.
- Используется стандартная библиотека; сторонние зависимости не нужны.
- Отдельная сборка не требуется: исходный файл выполняет Python.

## Запуск

Открыть терминал в корне репозитория и проверить Python:

```powershell
python --version
```

Запустить программу напрямую:

```powershell
python src/emulator.py
```

Или через скрипт Windows:

```powershell
.\run.bat
```

Скрипт определяет расположение исходного файла относительно себя,
поэтому его можно вызывать и из другой рабочей папки.
Если команда `python` недоступна, нужно добавить установленный Python
в PATH или запустить исходный файл через полный путь к интерпретатору.

После появления `vfs9$ ` вводить команды эмулятора, подтверждая их Enter.
Само приглашение вводить не нужно. Для завершения ввести `exit`.

## Команды и настройки

| Команда | Аргументы | Поведение этапа 1 |
| --- | --- | --- |
| `ls` | Без аргументов или один путь | Выводит имя `ls` и список аргументов |
| `cd` | Ровно один путь | Выводит имя `cd` и список аргументов |
| `exit` | Без аргументов | Завершает программу |

Количество аргументов — выбранное учебное ограничение прототипа.
Существование пути не проверяется. `cd` не меняет реальный каталог.
Неизвестная команда и неверное число аргументов вызывают сообщение
об ошибке; после этого программа продолжает принимать ввод.

Имена команд чувствительны к регистру. Ввод разбивается методом `split()`:
повторные пробелы и табуляции разделяют слова, пустой ввод пропускается.
Кавычки не объединяют слова; опции, конвейеры, перенаправления
и подстановки не интерпретируются, их символы остаются текстом аргументов.

Пользовательских настроек и параметров командной строки на этапе 1 нет.
Имя VFS задано в приглашении программы. Настройка запуска появится
на следующем этапе.

## Примеры использования

```text
vfs9$ ls
ls: аргументы = []
vfs9$ ls /home
ls: аргументы = ['/home']
vfs9$ cd /home
cd: аргументы = ['/home']
vfs9$ unknown
Ошибка: неизвестная команда unknown.
vfs9$ cd
Ошибка: cd ожидает ровно один аргумент-путь.
vfs9$ exit extra
Ошибка: exit не принимает аргументы.
vfs9$ exit
```

## Проверка

На этапе 1 используются ручные проверки; автоматических тестов пока нет.
Для начала проверки запустить программу:

```powershell
python src/emulator.py
```

Затем выполнить ручные проверки:

| Ввод | Ожидаемый результат |
| --- | --- |
| Пустая строка или только пробелы | Новое приглашение без ошибки |
| `ls` | Имя команды и пустой список аргументов |
| `ls /home` | Имя команды и аргумент `/home` |
| `  cd   /home  ` | Имя `cd` и один аргумент `/home` |
| `unknown` | Ошибка неизвестной команды |
| `ls /a /b` | Ошибка числа аргументов |
| `cd` или `cd /a /b` | Ошибка числа аргументов |
| `exit extra` | Ошибка аргументов; программа продолжает работу |
| `ls` после ошибки | Команда успешно выполняется |
| `exit` | Программа завершается |
