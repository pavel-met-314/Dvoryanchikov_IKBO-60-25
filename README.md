# Практическая работа №1

Конфигурационное управление. Вариант 9.

## О программе

Эмулятор командной строки на Python. Для окна используется Tkinter.
Сделан первый этап: ввод команд, разделение команды и аргументов,
проверка ошибок, заглушки ls и cd, выход по команде exit.

Перед вводом выводится `vfs9$ `, где `vfs9` — имя VFS.
Файловая система пока не загружается.

## Запуск

Нужен Python с Tkinter. Программа проверялась на Python 3.13.12.
Дополнительные библиотеки устанавливать не нужно. Сборка не требуется.

В папке проекта выполнить:

```powershell
python src/terminal_window.py
```

Или запустить через скрипт:

```powershell
.\run.bat
```

Откроется окно. Команды нужно вводить после `vfs9$ ` и нажимать Enter.

## Команды

- `ls` или `ls путь` — выводит имя команды и её аргументы.
- `cd путь` — выводит имя команды и её аргументы. Нужен ровно один путь.
- `exit` — закрывает окно. Аргументы не принимает.

Команды ls и cd пока работают как заглушки: файлы не показывают
и каталог не меняют. При неизвестной команде или неверном числе
аргументов выводится ошибка.

Настроек запуска пока нет. Имя VFS задано в переменной `VFS_NAME`.

## Пример

```text
vfs9$ ls
ls: аргументы = []
vfs9$ ls /home
ls: аргументы = ['/home']
vfs9$ cd /home
cd: аргументы = ['/home']
vfs9$ hello
Ошибка: неизвестная команда hello.
vfs9$ cd
Ошибка: cd ожидает ровно один путь.
vfs9$ exit extra
Ошибка: exit не принимает аргументы.
vfs9$ exit
```

После последней команды окно закрывается.

## Проверка

Автоматических тестов нет. Для ручной проверки запустить программу
командой `python src/terminal_window.py` и ввести команды из примера.

Дополнительно проверить:

- Пустой ввод — появляется новое приглашение.
- `  ls   /home  ` — лишние пробелы не мешают разбору.
- `ls /a /b` и `cd /a /b` — появляется ошибка числа аргументов.
- После ошибки можно ввести правильную команду и продолжить работу.
